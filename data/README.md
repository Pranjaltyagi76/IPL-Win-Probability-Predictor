# Data

Both files here are generated by `src/build_dataset.py` from the
[Cricsheet](https://cricsheet.org/) IPL archive, used under the Open Data
Commons Attribution License. Do not edit them by hand — rebuild instead:

```bash
python src/build_dataset.py --force-download
```

| File | Contents |
| --- | --- |
| `matches_all.csv` | One row per match, 2008–2026: result, venue, target, DLS flag |
| `deliveries_all.csv.gz` | One row per delivery: runs, legal-ball and wicket flags |

The delivery table is gzipped and read directly by pandas. `raw/` caches the
downloaded upstream archive and is gitignored.

Earlier versions of this project used a Kaggle export covering 2008–2019
(`matches.csv` / `deliveries.csv`). It was replaced because it stopped before
four of the current franchises existed. It remains available in the git history.
